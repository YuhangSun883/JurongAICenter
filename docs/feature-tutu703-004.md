# feature/tutu703-004 变更说明

## 目标
- 让画布历史、默认画布和当前画布数据分开。
- 让新建节点始终绑定当前 `canvasId`，避免写进默认画布。
- 保持前后端都走同一套画布数据结构，便于后面合并。

## 本次调整
- `/canvas` 历史页会过滤掉 `默认画布` 这类技术兜底数据。
- `/canvas/new` 新建节点时会带上当前 `canvasId`。
- 画布历史只展示用户画布，不再把默认画布当正常记录。
- 画布 mock / real API 补了 `updateCanvas` 和 `deleteCanvas`。
- 画布页面保留缩放、拖拽、改名、删除等操作。

## 启动与验证
- 前端已可在本地启动。
- 验证地址：`http://localhost:3001/canvas`
